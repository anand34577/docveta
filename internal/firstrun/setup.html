The first start downloads PostgreSQL (15–60 MB) and takes about a minute.

Don't have PostgreSQL yet?

Windows / macOS: install it from postgresql.org/download, remember the password you choose for the postgres user, and enter postgres and that password above with "Create the database" ticked.

Debian / Ubuntu:

sudo apt install postgresql postgresql-contrib
sudo -u postgres createuser --pwprompt docveta
sudo -u postgres createdb --owner docveta docveta

Step-by-step guides for every system are in the Docveta wiki.
